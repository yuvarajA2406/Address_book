# Address_book
Developed a menu-driven Address Book application in C to add, search, edit, delete, and display contact details using structured data management and file handling.

Project Overview

The Address Book is a menu-driven application developed using the C programming language to manage contact information efficiently. It allows users to store, search, update, delete, and display contact details.

Features

Add Contact: Store new contact details.
Search Contact: Find contacts using a name or phone number.
Edit Contact: Update existing contact information.
Delete Contact: Remove unwanted contacts.
Display Contacts: View all saved contacts.
File Handling: Store contact information in a file for future use.

Technologies Used

Programming Language: C
Concepts: Structures, Functions, Pointers, Arrays, and File Handling
Development Environment: GCC / VS Code

Working Principle

The application displays a menu of available operations.
The user selects an operation.
Contact details are added, searched, modified, deleted, or displayed.
File handling can be used to preserve contact information between program executions.
